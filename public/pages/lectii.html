De la idee la rezolvare
FUNCȚII

Ecuația de gradul al doilea

ax² + bx + c = 0
  1. Calculează discriminantul: Δ = b² − 4ac.
  2. Dacă Δ > 0, există două soluții reale.
  3. Aplică formula: x₁,₂ = (−b ± √Δ) / 2a.

Exemplu: x² − 5x + 6 = 0 → Δ = 1 → x₁ = 2, x₂ = 3.

DERIVATE

Derivata unei funcții

(xⁿ)' = n · xⁿ⁻¹
  1. Descompune funcția în termeni simpli.
  2. Aplică regula fiecărui termen.
  3. Adună derivatele obținute.

Exemplu: f(x) = 3x² − 4x + 1 → f'(x) = 6x − 4.

INTEGRALE

Primitiva unei puteri

∫ xⁿ dx = xⁿ⁺¹ / (n + 1) + C
  1. Identifică exponentul n.
  2. Adaugă 1 la exponent.
  3. Împarte la noul exponent și adaugă C.

Exemplu: ∫ 6x² dx = 2x³ + C.

PROBABILITĂȚI

Probabilitatea unui eveniment

P(A) = cazuri favorabile / cazuri posibile
  1. Numără toate rezultatele posibile.
  2. Numără rezultatele care respectă cerința.
  3. Împarte și simplifică fracția.

Exemplu: la un zar, P(număr par) = 3 / 6 = 1 / 2.
